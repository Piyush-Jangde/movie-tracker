# Movie Tracker API

A backend API for a personal movie and TV series tracker.

## Features

- User registration and login
- JWT authentication
- Protected routes
- Add / update / delete watchlist items
- Search and filter watchlist
- Pagination
- Track progress for TV series
- Favorites
- Ratings
- Watchlist statistics
- OMDb search integration
- Save directly from OMDb
- Duplicate prevention
- Input validation
- Centralized error handling

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- express-validator
- Axios
- OMDb API

## Installation

```bash
git clone <your-repo-url>
cd movie-tracker-backend
npm install
```
