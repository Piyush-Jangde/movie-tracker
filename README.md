# Movie Tracker

A full-stack web application to track movies and TV series, manage watchlists, monitor episode progress, and analyze viewing habits.

## Features

### Core Features
- User authentication (signup/login)
- Personal watchlist management
- Track movies and TV series separately
- Update viewing status:
  - Want to Watch
  - Watching
  - Completed
  - On Hold
  - Dropped
- Episode and season progress tracking
- Personal ratings and notes

### Discovery & Search
- Search and import movie/series metadata using TMDb API
- Automatic posters, genres, release dates, and descriptions

### Dashboard & Analytics
- Total watched content
- Viewing statistics
- Favorite genres
- Watching activity over time

### Chrome Extension (Planned)
- Add movies/shows directly from IMDb or other streaming websites
- One-click save to watchlist

### Mobile App (Future)
- Android app for managing your tracker on the go
